```

👉 Дважды кликните: 360-assessment-system.sln
```

### Шаг 2: Экспортируйте проект

#### Если используете Figma Make:
1. Нажмите кнопку **"Download"** или **"Export"**
2. Скачайте ZIP архив со всеми файлами
3. Распакуйте на вашем компьютере

#### Если копируете вручную:
1. Откройте файл **EXPORT_INSTRUCTIONS.md**
2. Следуйте пошаговой инструкции
3. Используйте **EXPORT_CHECKLIST.md** для проверки

### Шаг 3: Запустите проект

```bash
# Перейдите в папку проекта
cd 360-assessment-system

# Установите зависимости
npm install

# Запустите проект
npm run dev

# Откройте в браузере
# http://localhost:5173
```
