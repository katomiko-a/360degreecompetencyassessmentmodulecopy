## 🚀 Как запустить

### Первый запуск (для нового пользователя)

```bash
# 1. Убедитесь, что Node.js установлен
node --version  # должно быть 18+

# 2. Установите зависимости
npm install

# 3. Запустите проект
npm run dev

# 4. Откройте браузер
# http://localhost:5173
```

### Первая регистрация

1. При запуске увидите форму входа
2. Нажмите **"Зарегистрироваться"**
3. Заполните форму:
   ```
   Email: admin@example.com
   Password: admin123
   Имя: Администратор
   Роль: Администратор
   Отдел: IT
   ```
4. Нажмите **"Зарегистрироваться"**
5. Вы будете автоматически перенаправлены на страницу входа
6. Войдите с созданными учетными данными

### Создание тестовых данных

1. После входа нажмите **"Создать новую кампанию"**
2. Заполните данные кампании
3. Добавьте участников
4. Создайте анкету с компетенциями
5. Опубликуйте кампанию

## 🔐 Безопасность

### Реализованные меры:

1. **JWT Authentication**
   - Токены выдаются через Supabase Auth
   - Автоматическая проверка на каждом endpoint

2. **Role-based Access Control**
   - Администраторы и сотрудники имеют разные права
   - Проверка прав на уровне сервера

3. **Data Filtering**
   - Сотрудники видят только свои данные
   - Администраторы видят все данные

4. **Input Validation**
   - Проверка обязательных полей
   - Валидация типов данных

5. **Error Handling**
   - Детальное логирование ошибок
   - Безопасные сообщения для пользователей

## 📈 Генерация отчетов

Backend автоматически генерирует отчеты с:

### 1. Средние оценки по компетенциям
```javascript
{
  "competencyId": {
    "name": "Лидерство",
    "overall": 4.2,
    "byRole": {
      "self": 4.5,
      "manager": 4.0,
      "peer": 4.1,
      "subordinate": 4.3
    }
  }
}
```

### 2. Gap Analysis
```javascript
{
  "competencyId": {
    "name": "Лидерство",
    "selfScore": 4.5,
    "othersScore": 4.13,
    "gap": 0.37  // положительное = переоценка, отрицательное = недооценка
  }
}
```

### 3. Персонализированные рекомендации

Автоматически генерируются на основе:
- Разрыва между самооценкой и оценкой окружающих
- Низких оценок (< 3.0)
- Паттернов в данных

Примеры рекомендаций:
- "Переоценка компетенции 'Планирование': ваша самооценка выше оценки окружающих на 1.2 балла..."
- "Компетенция 'Коммуникация' требует развития. Средняя оценка окружающих: 2.8..."
- "Недооценка компетенции 'Технические навыки': окружающие оценивают вас выше на 1.5 балла..."

## 🐛 Troubleshooting

### Ошибка "Unauthorized" при API запросах

**Причина:** Не установлен или истек access token

**Решение:**
```typescript
import { setAccessToken } from './utils/api';

// После успешного входа
const { data: { session } } = await supabase.auth.signInWithPassword({...});
setAccessToken(session.access_token);
```

### Ошибка "403 Forbidden"

**Причина:** Недостаточно прав (например, сотрудник пытается создать кампанию)

**Решение:** Проверьте роль пользователя в профиле. Только администраторы могут создавать/редактировать кампании.

### Ошибка "CORS"

**Причина:** CORS настроен неправильно

**Решение:** В `/supabase/functions/server/index.tsx` уже настроен CORS:
```typescript
app.use('*', cors());
```

### Данные не сохраняются

**Причина:** Возможно, проблема с KV Store

**Решение:** Проверьте логи в Supabase Dashboard → Edge Functions → Logs
