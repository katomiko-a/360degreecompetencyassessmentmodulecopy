## 📖 Что это за проект?

**Система оценки компетенций 360 градусов** - это полнофункциональное веб-приложение на React + TypeScript + Supabase Backend для проведения оценки персонала с возможностью:

✨ **Backend на Supabase** с аутентификацией и API  
✨ Создания кампаний оценки  
✨ Управления участниками и анкетами  
✨ Прохождения оценок  
✨ Детальных отчетов с графиками и gap analysis  
✨ Персонализированных рекомендаций  
✨ Уведомлений и личного кабинета  

**Интерфейс:** Полностью на русском языке  
**Дизайн:** Сиреневая цветовая схема  
**Backend:** Supabase Edge Functions (Hono + Deno)

## ❓ FAQ - Частые вопросы

### Q: Какую IDE выбрать?
**A:** Для React проектов рекомендуется **Visual Studio Code** - он легче и быстрее.

### Q: Нужен ли мне файл .sln?
**A:** Только если вы используете Visual Studio (не VS Code). Для VS Code он не нужен.

### Q: Как изменить порт?
**A:** Откройте `vite.config.ts` и добавьте `server: { port: 3000 }` в конфигурацию.

### Q: Где находятся стили?
**A:** Глобальные стили в `src/styles/globals.css`, компонентные стили используют Tailwind CSS классы.

### Q: Как добавить новый компонент?
**A:** Создайте файл в `src/components/`, следуя примерам существующих компонентов.

## 🆘 Что-то не работает?

### Ошибка при установке зависимостей:
```bash
rm -rf node_modules package-lock.json
npm install
```

### Порт 5173 уже занят:
Измените порт в `vite.config.ts` или закройте другие приложения

### TypeScript ошибки:
Перезапустите TypeScript сервер в VS Code:
`Ctrl+Shift+P` → "TypeScript: Restart TS Server"

### Другие проблемы:
Читайте соответствующий раздел в:
- `INSTALLATION_GUIDE.md` (для VS Code)
- `VISUAL_STUDIO_GUIDE.md` (для Visual Studio)
