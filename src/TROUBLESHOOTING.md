# 🔧 Решение проблем

## ❌ Ошибка: "Подтип проекта не поддерживается этой установкой"

### Описание проблемы:
```
Отсутствует подтип проекта.
Подтип: "{3AF33F2E-1736-4565-8C3A-E88EAF3E4DFF}" не поддерживается этой установкой.
```

Эта ошибка означает, что в Visual Studio не установлены **Node.js Tools**.

---

## ✅ Решение 1: Использовать Visual Studio Code (РЕКОМЕНДУЕТСЯ!)

Для React/TypeScript проектов **VS Code** - это лучший выбор:

### Преимущества VS Code:
✅ Легкий и быстрый (200 MB vs 10+ GB)  
✅ Не требует специальных компонентов  
✅ Лучшая поддержка React/TypeScript  
✅ Бесплатный и популярный среди React-разработчиков  
✅ Файлы .sln не нужны!  

### Как использовать VS Code:

1. **Скачайте VS Code:**
   - https://code.visualstudio.com/

2. **Откройте проект:**
   ```bash
   cd 360-assessment-system
   code .
   ```

3. **Следуйте инструкции:**
   - Откройте файл `INSTALLATION_GUIDE.md`
   - Выполните команды из раздела "Установка и запуск"

4. **Быстрый старт:**
   ```bash
   npm install
   npm run dev
   ```

**Готово!** Проект запустится без проблем!

## ✅ Решение 2: Установить Node.js Tools в Visual Studio

Если вы хотите использовать именно Visual Studio (не VS Code):

### Шаг 1: Откройте Visual Studio Installer

1. Закройте Visual Studio
2. Откройте **Visual Studio Installer**
   - Найдите в меню Пуск: "Visual Studio Installer"
   - Или скачайте: https://visualstudio.microsoft.com/

### Шаг 2: Измените установку

1. Найдите вашу версию Visual Studio (2019/2022)
2. Нажмите кнопку **"Изменить"** (Modify)

### Шаг 3: Установите Node.js Development

1. В окне установки перейдите на вкладку **"Рабочие нагрузки"** (Workloads)
2. Найдите и отметьте: **"Разработка Node.js"** (Node.js development)
3. Справа убедитесь, что выбраны:
   - ✅ Node.js development tools
   - ✅ TypeScript and JavaScript language support
4. Нажмите **"Изменить"** (Modify)
5. Дождитесь установки (может занять 10-30 минут)

### Шаг 4: Перезапустите Visual Studio

1. После установки запустите Visual Studio
2. Откройте файл `360-assessment-system.sln`
3. Проект должен открыться без ошибок!

## ✅ Решение 3: Использовать проект без .sln файла

Можно работать с проектом в Visual Studio без файла .sln:

### Вариант А: Открыть папку в Visual Studio 2022

Visual Studio 2022 поддерживает открытие папок напрямую:

1. Откройте Visual Studio 2022
2. Выберите **"Открыть локальную папку"** (Open a local folder)
3. Выберите папку `360-assessment-system`
4. Visual Studio автоматически определит проект по `package.json`

### Вариант Б: Использовать терминал

1. Откройте Visual Studio
2. Создайте пустое решение или проект
3. Используйте встроенный терминал:
   - `View` → `Terminal`
   - Перейдите в папку проекта: `cd path/to/360-assessment-system`
   - Выполните: `npm install` и `npm run dev`

## 🆘 Другие частые проблемы

### Проблема: "npm command not found"
**Решение:** Установите Node.js с https://nodejs.org/

### Проблема: "Port 5173 already in use"
**Решение:** 
- Закройте другие приложения на этом порту
- Или измените порт в `vite.config.ts`:
  ```typescript
  export default defineConfig({
    plugins: [react(), tailwindcss()],
    server: {
      port: 3000 // новый порт
    }
  });
  ```

### Проблема: "Cannot find module"
**Решение:**
```bash
rm -rf node_modules package-lock.json
npm install
```

### Проблема: TypeScript ошибки
**Решение:**
- В VS Code: `Ctrl+Shift+P` → "TypeScript: Restart TS Server"
- Или: `npx tsc --noEmit` для проверки ошибок

### Проблема: Стили не применяются
**Решение:**
- Проверьте, что `globals.css` импортирован в `src/main.tsx`
- Перезапустите dev-сервер: `npm run dev`
