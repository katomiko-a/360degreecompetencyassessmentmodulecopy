## Настройка (5 минут)

### Шаг 1: Supabase (обязательно)
1. Откройте приложение в браузере
2. Появится модальное окно для подключения
3. Перейдите на [supabase.com](https://supabase.com)
4. Создайте проект (бесплатно)
5. Скопируйте **Project URL** и **Anon Key**
6. Вставьте в модальное окно

### Шаг 2: Resend (опционально, для email)
1. Зарегистрируйтесь на [resend.com](https://resend.com/signup)
2. Создайте API ключ
3. В приложении: Уведомления → Добавить API ключ

## Нужна помощь?

### "Cannot find module"
```bash
rm -rf node_modules package-lock.json
npm install
```

### "Port already in use"
```bash
# Завершите процесс на порту 5173
lsof -ti:5173 | xargs kill
```

### Supabase не подключается
1. Проверьте, что скопировали правильные ключи
2. Убедитесь, что проект Supabase активен
3. Попробуйте переподключиться

### Email не отправляются
1. Убедитесь, что API ключ Resend начинается с `re_`
2. Проверьте, что ключ активен на resend.com
3. Создайте новый ключ если нужно
