## 🔧 Инструкции для пользователя

### Шаг 1: Установка
```bash
cd 360-assessment-system
npm install
```

### Шаг 2: Настройка VS Code
1. Откройте папку в VS Code
2. Установите рекомендуемые расширения
3. Перезапустите VS Code

### Шаг 3: Запуск
```bash
npm run dev
```

### Шаг 4: Настройка Supabase
1. Откройте http://localhost:5173
2. Подключите Supabase через модальное окно
3. Скопируйте URL и Anon Key

### Шаг 5: Настройка Email
1. Зарегистрируйтесь на resend.com
2. Создайте API ключ
3. Добавьте через интерфейс
