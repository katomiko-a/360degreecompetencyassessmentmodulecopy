# Система оценки 360° - Запуск в VS Code

## 🚀 Три команды для запуска

```bash
# 1. Установите зависимости
npm install

# 2. Запустите проект
npm run dev

# 3. Откройте браузер
# http://localhost:5173
```

## ⚙️ Настройка (после запуска)

1. **Supabase** (обязательно):
   - Откройте приложение в браузере
   - Следуйте инструкциям в модальном окне
   - Зарегистрируйтесь на supabase.com
   - Скопируйте Project URL и Anon Key

2. **Resend** (опционально, для email):
   - Зарегистрируйтесь на resend.com
   - Создайте API ключ
   - Добавьте в разделе "Уведомления"
